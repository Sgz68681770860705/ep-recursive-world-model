# EP Recursive Collision–Phase-Transition World Model

**From local collisions to a recursively emerging world.**

[English](README.md) | [简体中文](README.zh-CN.md)

> **Can a universe emerge from collisions?**

EP is an open research program exploring a generative model of physical reality.

We begin with a deliberately minimal question:

> Can one type of deep-level constituent and one unified local collision rule generate space, stable structures, propagation, motion, inertia, interactions, probability, and recursively emerging physical hierarchies?

Rather than assigning separate fundamental rules to every known phenomenon, we investigate whether increasingly complex physical reality can emerge, layer by layer, from a common underlying dynamics.

## The Vision

What if space is not an empty container, but a statistical background formed by continuously moving and colliding constituents?

What if matter is not a separate substance, but a stable phase structure maintained through continuous exchange with that background?

What if propagation, motion, inertia, and force are different statistical expressions of the same collision dynamics?

What if stable structures can become effective constituents at a higher scale, allowing the world to develop recursively?

These are research questions—not established conclusions.
