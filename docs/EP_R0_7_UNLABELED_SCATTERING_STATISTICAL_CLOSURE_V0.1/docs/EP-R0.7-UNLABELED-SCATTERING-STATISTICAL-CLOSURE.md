# EP-R0.7: Unlabeled Scattering Map and Statistical Closure

Status:

`[DERIVED DEFINITIONS FOR AN UNLABELED SCATTERING MAP] + [EXPLORATORY NUMERICAL — SCATTERING MAP PASSED; UNIVERSAL SINGLE-POLE CLOSURE FAILED] + [OHMIC VISCOSITY CLOSURE OPEN]`

A frozen scan of 105 cubic–quintic single-field collision events was performed over speed, relative phase, and impact parameter. Incoming and outgoing structures are unordered connected-component observables rather than labeled particles.

The scan produced four main branches: 33 persistent-fusion candidates, 40 fusion–fission scattering events, 22 two-component scattering events, and 10 fragmentation events.

Eight representative points were rerun at higher resolution, with classification agreement 1.000. A separate high-resolution conservation run passed norm, Hamiltonian, momentum, and time-reversal gates.

An integrated anisotropic gradient-stress activity was used to define event impulse and equivalent duration. The mean equivalent time was 4.303256, with coefficient of variation 0.390379.

A universal single-exponential envelope achieved only R²=0.812753, below the frozen 0.90 gate, while the duration coefficient of variation exceeded the frozen 0.30 gate. The scattering-map gate passed, but the universal one-pole closure failed.

The data therefore require class-conditioned or multi-timescale memory kernels. The aligned activity envelope is not yet a Green–Kubo viscosity kernel; event rates, stationarity, wave-number resolution, and a validated low-frequency Ohmic limit remain open.
