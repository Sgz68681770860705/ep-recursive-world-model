本文件不是论文，也不是最终理论。它只记录：

我们不要求一次列出全部核心问题。每次只把当前已经看清的问题写清楚。

## 2. 总目标

EP研究计划试图回答：

> 是否存在一个足够小、足够统一的局部更新或碰撞模型，使空间、稳定结构、传播、惯性、有效相互作用和递归层级能够在未被预先写入的情况下涌现？

当前不宣称EP正确。当前目标是寻找可以计算、比较和证伪的最小模型。

## 3. 当前基本立场

EP底层暂不把“力”视为基本对象，只描述：

- 局部状态；
- 局部运动；
- 碰撞、交换或重构；
- 边界状态；
- 能量与动量账本；
- 层级之间的粗粒化。

高层所说的“力”暂定义为边界净动量通量：

\[
F_i=-\oint_{\partial\Omega}\Pi_{ij}n_j\,dA
\]

吸引与排斥都应当从同一个通量差中产生，而不是作为两种预设基本力加入。

## 4. 当前问题索引

### Q001：长程吸引、边界作用和短程斥力能否来自同一个递归碰撞统计机制？

## 5. 需要依次解决的问题

### 第一层：定义

1. 什么是 \(S_0\)？
2. 什么是 \(S_{-1}\) 背景？
3. \(S_0\) 边界如何改变 \(S_{-1}\) 的入射、反射、锁定与释放？
4. “碰撞”是瞬时接触，还是连续相互作用进入强耦合区？
5. 如何定义动量通量张量和边界净作用？

### 第二层：远场

1. 单个边界是否产生无隙、守恒的低波数响应？
2. 该响应能否在三维各向同性空间中按球面稀释？
3. 能否在不写入 \(1/r^2\) 的情况下得到远场平方反比？
4. 是否出现屏蔽、阻力、持续加热或材料依赖？

### 第三层：边界与中近场

1. 两个边界靠近时，中间允许的背景模式如何改变？
2. 边界内外动量通量差能否产生吸引？
3. 幂次是否由几何、维数、边界条件和源结构共同决定？
4. 同一规则能否处理平行边界、球形对象和局域中性对象？

### 第四层：高密度与斥力

1. 随距离缩短，中间密度、碰撞率、反射率和关联是否增长？
2. 是否存在 \(P_{gap}=P_{out}\) 的临界点？
3. 更近时是否出现 \(P_{gap}>P_{out}\) 的斥力分支？
4. 相对速度是否使符号翻转更早出现？
5. 平衡点附近是否自然得到 \(Fpprox-k(r-r_*)\)？

### 第五层：统一性

1. 远场、中近场和极近场能否使用同一个碰撞算子？
2. 是否只改变距离、几何、边界状态与速度，而不更换规则？
3. 参数能否跨尺度复用？
4. 如果每个现象都需要额外补丁，应判定统一失败。
