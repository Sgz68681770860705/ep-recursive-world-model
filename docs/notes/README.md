## Claim labels / 结论标签

- `[POSTULATE]` — assumed starting point / 起始公设
- `[DEFINITION]` — chosen mathematical meaning / 数学定义
- `[CONJECTURE]` — proposed but not proved / 尚未证明的猜想
- `[DERIVED]` — derived from stated assumptions / 条件明确的推导结果
- `[NUMERICAL]` — supported by computation / 数值结果
- `[EMPIRICAL]` — compared with observation / 经验比较
- `[FAILED]` — contradicted or unsuccessful route / 失败路线
- `[OPEN]` — unresolved / 开放问题
