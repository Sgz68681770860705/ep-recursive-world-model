# GitHub Upload Instructions

Place this folder under a research or theory directory, for example:

`research/EP_R0_4_FINITE_PHASE_BOUNDARY_COLLISION_LEDGER_V0.1/`

Suggested commit:

`theory: add EP-R0.4 finite-boundary collision ledger`

Keep the scope label intact. The package validates a Gaussian finite-boundary collision ledger. It does not yet demonstrate phase-field fusion or reconstruction.
