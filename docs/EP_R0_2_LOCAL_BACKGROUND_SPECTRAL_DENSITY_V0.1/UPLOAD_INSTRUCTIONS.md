`research/EP_R0_2_LOCAL_BACKGROUND_SPECTRAL_DENSITY_V0.1/`

Suggested commit:

`theory: derive EP-R0.2 local-background spectral density`

Keep the status label exactly as written. This package derives a spectral density in a specific local linear field model; it is not yet a derivation of measured real-fluid viscosity.
