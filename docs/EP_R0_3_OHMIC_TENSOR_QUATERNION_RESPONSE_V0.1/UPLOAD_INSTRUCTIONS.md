# GitHub Upload Instructions

Place the folder under a research or theory directory, for example:

`research/EP_R0_3_OHMIC_TENSOR_QUATERNION_RESPONSE_V0.1/`

Suggested commit:

`theory: add EP-R0.3 Ohmic tensor and quaternion response`

Keep the status boundary intact. The package establishes a minimal linear internal-field model, not a derivation of real-fluid tensor viscosity.
