# EP递归碰撞—相变世界模型：研究基石

**版本：V0.1**  
**日期：2026-07-07**  
**文档状态：研究纲领 / 非最终理论结论**

> 本文件用于保存模型当前的核心前提、术语、逻辑边界和下一步研究方向。它不是论文，也不代表模型已经得到数学证明或实验确认。


## 一、总目标


目标不是先把现有物理学公式拼接进模型，也不是预先规定光、电子、引力、量子、四元数或希尔伯特空间。

目标是从尽可能少的底层前提出发，尝试逐层涌现：

1. 空间的统计背景；
2. 传播模式；
3. 相变体；
4. 质量、运动、惯性；
5. 力与场；
6. 量子概率和希尔伯特空间；
7. 递归层级；
8. 最终形成一套可计算、可证伪的“生成式公理化物理学”。

核心态度：

- 不把希望得到的结果预先写进公理；
- 不用“因为现有物理这样说”直接否定底层模型；
- 现有物理的实验事实仍然必须作为最终输出闸门；
- 优雅不能替代推导，但优雅可以指导寻找最小规则；
- 所有“必然”都必须区分：逻辑必然、模型内必然、统计高概率、经验匹配。

## 二、层级与基本术语


1. S-1 层

S-1 是比可观测 S0 更深的基础层。

暂定图景：

- S-1 基元具有极高本征运动速度；
- 它们在空间中持续运动、碰撞和交换动量；
- 在均匀区域，其方向分布在统计上快速趋向各向同性；
- 平均动量可以为零，但动量通量和压力不为零；
- S-1 的个体速度可以高于 S0 层可观测光型模式的传播速度；
- “个体速度高于集体模式速度”本身不是逻辑矛盾，正如介质粒子速度与波速不是同一个概念；
- 是否能够传递可控超光速信息，必须后续单独检验，不能预先假定。

2. S0 层

S0 是由 S-1 聚集、锁定并通过持续 in/out 交换维持的最小可观测相变基元。

S0 的暂定性质：

- 有有限体积；
- 是能量—动量的最小可观测载体；
- 在相同 S-1 环境密度下，同类 S0 等大、等能；
- 不是完全封闭的硬球，而是动态相变稳态；
- 内部具体 S-1 成员可以不断更换；
- 对象身份属于稳定的边界、动量分布和 in/out 统计结构，而不是固定成员编号；
- S0 周围仍充满 S-1 背景；
- S0 的边界会改变 S-1 的入射、出射、局部密度、涨落谱和动量通量。

3. S1 及更高层

多个 S0 在一定条件下可能形成稳定的高层相变体 S1。

高层对象只有在满足下列条件时，才有资格被定义：

- 具有有限尺度；
- 内部快速混合，外部慢响应；
- 身份寿命远大于内部碰撞时间；
- 对外只需少量状态变量即可描述；
- 不同内部微态在外部观测上近似等价；
- 能够定义新的 in/out、边界、动量和碰撞规则。

递归不是预设公理，而是待发现的结果：

下层大量自由度
→ 稳定相变体
→ 外部等价类
→ 新的有效对象
→ 检查其动力学是否与下层经尺度重标定后同构。

## 三、空间、物质和能量的统一图景


1. 空间不是“空无”

空间是未锁定的深层基元统计态。

可暂时理解为：

空间 = S-1 的高速碰撞背景及其统计分布。

2. 物质不是另一种本体

物质是同一种基质的闭合相变稳态：

物质 = 深层基元的局部锁定 + 稳定边界 + 持续 in/out 动态平衡。

3. 能量不是与物质分离的“抽象数字”

能量是深层基元运动、相互作用、锁定、边界和传播状态的统一守恒账本。

因此模型追求的是：

空间、能量、物质
不是三种独立本体，
而是同一底层基质的不同统计组织形式。

## 四、in/out 动态平衡是核心


S0 或高层相变体即使宏观静止，内部仍然可以存在大量高速 S-1 运动与交换。

静止只表示：

- 总动量统计平衡；
- 净粒子通量为零；
- 净能量通量为零；
- 边界和宏观形态稳定。

不表示：

- 内部成员不运动；
- 没有 S-1 进入；
- 没有 S-1 退出。

稳定相变体应满足：

J_in ≠ 0
J_out ≠ 0

但长期平均：

净成员变化 = 0
净能量变化 = 0
净总动量变化 = 0

运动状态也是一种 in/out 平衡，而不是“物体穿过介质并持续对抗阻力”。

## 五、运动、动量、速度和惯性


1. 动量偏置

例如一个由 10000 个 S-1 构成的相变体中：

- 2000 个向右；
- 1000 个向左；
- 其余 7000 个矢量和为零；

那么这个相变结构具有向右的净动量偏置。

但这只能直接推出“总动量状态”，不能直接推出速度。

2. 禁止的错误推导

不能直接写：

速度 = 净向右数量 / 总数量 × S-1 速度。

原因：

- 相变边界携带动量；
- 近场环境携带动量；
- 束缚能参与总能量；
- in/out 成员持续替换；
- 还没有先验的 P = MV；
- 惯性不能提前写入。

3. 正确顺序

方向占据不平衡
→ 定义相变体总动量 P
→ 求移动稳定解
→ 得到能量—动量关系 E(P)
→ 速度由稳定解的平移率或 dE/dP 得到
→ 惯性由改变稳定运动状态所需的动量代价得到。

4. 匀速运动的定义

匀速运动不是“不断受到阻力又不断补充能量”。

匀速运动是：

相变体与空间之间一个前后不对称、但总账本平衡的移动固定点。

在共动坐标中，内部统计结构保持不变。

5. 所谓“以太阻力”

前方入射增强不应自动叫作阻力。

应区分：

- 运动态的 in/out 各向异性；
- 真正导致总动量随时间减少的剩余不平衡。

只有后者才是耗散阻力。

速度可能就是这种 in/out 定向分布的一阶统计投影。

## 六、碰撞统计、压力和力


1. 均匀背景

均匀 S-1 背景中：

- 各方向平均碰撞对称；
- 单个孤立边界四周总动量通量相等；
- 因而净力为零。

2. 边界作用

S0/S1 边界不是被动硬壳，而是会：

- 吸收；
- 锁定；
- 重排；
- 反射；
- 释放 S-1。

两个边界靠近时，会共同改变中间区域的：

- 可入射方向；
- 出射方向；
- 局部密度；
- 关联和涨落谱；
- 动量通量张量。

因此两侧压力可不相等。

3. 力的统一表达

力不是预先存在的“吸引线”。

力是边界上动量通量统计的不平衡。

宏观吸引或排斥，是外侧与内侧碰撞统计差的结果。

4. 水中类 Casimir 现象的启发

现实液体中，边界限制介质涨落、分子排列和电磁响应，确实能产生：

- 吸引；
- 排斥；
- 振荡势；
- 临界 Casimir 力；
- 溶剂化力；
- 水合力。

这说明：

边界改变介质允许状态和涨落谱
→ 可以产生有效力。

它支持模型的逻辑路线，但不证明所有边界作用都必然是引力。

水中作用多样，是因为水分子速度、粗糙度、电磁结合、表面化学和涨落尺度复杂。

5. 引力候选

模型中的引力不是一种先验吸引力。

候选机制是：

- 边界改变 S-1 的入射/出射统计；
- 两对象共同造成中间区域动量通量亏缺；
- 外侧压力大于内侧压力；
- 两对象被外部碰撞“推向彼此”。

若远场遮蔽或响应在三维空间中按立体角稀释，可能出现 1/r² 候选。

但真实引力资格仍需证明：

- 长程；
- 无屏蔽或极弱屏蔽；
- 近似 1/r²；
- 作用与总能量/质量成正比；
- 等效原理；
- 低阻力；
- 低加热；
- 普适耦合；
- 能解释光线弯曲等。

## 七、光的模型


1. 真空中的光

光不是一批固定 S0 从发射点一直飞到终点。

光是 S0/S-1 背景中的定向、相干、成员不断替换的传播模式。

传播的是：

- 动量方向；
- 相位；
- 组织形式；
- 碰撞接力模式。

不是固定成员。

2. 光与声的同构点

光和声音在“接力传播机制”上可同构：

局部状态
→ 传给前方成员
→ 后方成员退出
→ 模式向前传播。

但具体自由度不一定相同：

- 声音通常是纵向密度/压力模；
- 光必须最终解释横向性和两种偏振。

3. 光速

光速被理解为：

S0 层光型集体模式在特定背景中的特征传播速度。

它不必等于 S-1 个体速度，也不必是所有层级的绝对速度上限。

4. 光在介质中变慢

当玻璃等介质改变局部 S0/S-1 的：

- 有效密度；
- 碰撞更新率；
- 驻留时间；
- 响应刚度；
- in/out 重构过程；

光型模式的有效传播速度可以下降。

通过玻璃产生到达时间延迟，是模型必须恢复的基本事实。

严谨表述：

介质改变传播模式的接力时间和响应结构
→ 群速度下降
→ 光脉冲到达延迟。

暂时不应只写成“密度越大速度必然越慢”，因为速度还可能依赖响应刚度和共振结构。

5. 频率与强度

暂定区分：

- 频率：单个传播模式的相位更新率或内部相干更新率；
- 单光子能量：与相干占据量和相位频率有关；
- 强度：单位面积、单位时间到达的光型事件总能量统计。

不能简单把局部能量密度直接等同于频率，因为聚焦可提高密度而不改变频率。

6. 红移

密度梯度、背景变化或相干泄漏可能影响频率。

必须区分：

- 速度变化；
- 波长变化；
- 振幅衰减；
- 光子数减少；
- 单光子中心频率降低。

这些不能混为一谈。

## 八、相变体、质量和物质粒子


1. 光型态与物质态

光型态：

- 松散；
- 传播；
- 成员持续替换；
- 未形成稳定闭合边界。

物质态：

- 越过相变阈值；
- 形成闭合或准闭合边界；
- in/out 动态平衡；
- 具有长寿命；
- 具有静止能；
- 对外表现为稳定对象。

2. 质量候选

质量不预设为独立属性。

可以从以下结构中涌现：

- 相变自由能差；
- 内部稳定周期；
- 改变移动固定点所需的动量代价；
- 能量—动量色散关系。

3. 中微子/电子等命名

目前只能称为：

- 中性有质量相变体候选；
- 带取向不对称的相变体候选；
- 光型传播模候选。

在没有完整恢复已知粒子性质之前，不应直接宣称已得到真实中微子、电子或希格斯粒子。

## 九、洛伦兹结构的候选来源


1. 核心直觉

所有物质、光、尺子、时钟和探针都由同一 S-1 ↔ S0 in/out 相变机制构成。

当相变体相对于背景处于不同运动状态时，其：

- 入射分布；
- 出射分布；
- 边界形状；
- 内部周期；
- 近场结构；

会发生统一重构。

2. 洛伦兹不变的候选解释

洛伦兹变换可能不是底层先验，而是：

同一种相变结构在不同运动固定点之间，为维持 in/out 平衡而形成的普适变换规律。

3. 尚未证明的关键点

必须由底层方程推出：

- 连续移动固定点族；
- 这些固定点之间的速度组合规律；
- 统一极限速度；
- 统一时间延缓；
- 统一长度重构；
- 无普通真空阻力；
- 可观测层近似洛伦兹协变。

不能只靠“所有装置都变了所以看不见背景”作为完整证明。

## 十、希尔伯特空间的正确位置


1. 不把希尔伯特空间作为底层物理容器

物理碰撞发生在真实配置/相空间中。

希尔伯特空间是：

所有可能微观状态上的平方可积函数所构成的状态空间。

2. 自然产生的第一层希尔伯特表示

底层完整配置记为 Z。

所有可能配置构成 Ω。

定义：

H = L²(Ω, dμ)

内积表示状态函数重叠。

如果底层演化：

- 可逆；
- 保测度；

则它在 H 上诱导幺正演化算符。

这一步得到的首先是“经典动力系统的希尔伯特表示”，还不是完整量子力学。

3. 相变体的有效希尔伯特空间

长寿命相变体可被视为底层状态空间中的慢模、亚稳集合或外部等价类。

相变体的有效状态空间可由这些慢模生成。

4. 从经典 Hilbert 到量子 Hilbert 仍需推导

必须进一步得到：

- 物理叠加；
- 复相位干涉；
- Born 规则；
- 不对易可观察量；
- 张量积复合；
- 纠缠；
- Bell 关联。

“存在希尔伯特空间”不等于“已经得到量子力学”。

5. 碰撞与内积的区别

- 碰撞：演化映射或算符；
- 内积：状态重叠；
- 积分：统计汇总和期望；
- 碰撞不是点积；
- 碰撞统计也不等于内积本身。

## 十一、四元数的正确位置


第一层不预设四元数。

只有当高层相变体自然出现：

- 三维内部旋转；
- 左右手性；
- 两组复相位；
- 非交换旋转组合；
- 4π 周期；
- SU(2) 结构；

才引入单位四元数描述其内部取向。

正确顺序：

先发现内部模式
→ 计算其组合代数
→ 若同构于四元数/SU(2)
→ 再采用四元数语言。

四元数不是基础万能解释器，也不会自动产生自旋 1/2、费米统计或量子测量规则。

## 十二、递归与紧致维度


1. 递归

递归不是新正交空间轴。

递归是：

下层大量微态
→ 长寿命相变体
→ 外部等价类
→ 新的有效状态空间。

2. 时间尺度分层

快速碰撞、慢场、稳定对象、递归对象可以对应动力学生成元的不同谱带。

这首先是时间尺度/慢模分层，不是紧致维度。

3. 紧致维度候选

只有当高层相变体内部自然出现：

- 周期坐标；
- 明确边界条件；
- 内部度规；
- 离散本征谱；
- 类似 m²/R² 的激发塔；

才可以把内部状态空间几何化为“紧致维度”式描述。

紧致维度只能是后验等价解释，不能作为底层先验。

## 十三、当前严格禁止的先验


第一版底层模型中，不允许直接写入：

- 光子规则；
- 电子规则；
- 中微子规则；
- 引力势；
- 电荷；
- 质量；
- 相变序参量；
- 希尔伯特量子规则；
- 四元数；
- 紧致维度；
- Born 规则；
- 洛伦兹变换；
- 1/r² 力；
- 先验吸引势。

这些只能在运行统一底层规则后，由统计结构和稳定解中识别。

## 十四、最小生成核心


理论应尽量收缩为：

一种深层基元
+
一种统一局部更新/碰撞规则
+
允许自然形成 in/out 稳定相变体。

其他一切均为待推导结果。

最简符号：

世界模型 W = (Ω, U)

其中：

- Ω：所有底层配置；
- U：唯一局部演化/碰撞更新。

研究顺序：

U
→ 平衡统计
→ 密度、通量、应力
→ 边界条件
→ in/out 固定点
→ 传播模
→ 相变体
→ 移动固定点
→ 力与有效场
→ 慢模 Hilbert 空间
→ 复相位/量子检验
→ 递归。

## 十五、当前最核心的待推导问题


1. 什么是最小且统一的底层碰撞规则 U？
2. 为什么均匀背景会趋向最大熵/平衡统计？
3. S-1 如何聚集形成稳定 S0，而不是无限聚集或完全散开？
4. 为什么 S0 具有有限尺度？
5. 两个边界如何改变 S-1 的 in/out 分布？
6. 该分布何时表现为吸引、排斥、振荡势或潮汐？
7. 是否能从三维角分布中自然得到远场 1/r²？
8. 为什么作用与总能量/质量近似线性？
9. 是否存在一族无耗散或极低耗散的移动固定点？
10. 速度如何由 in/out 分布的稳定投影产生？
11. 惯性如何由改变固定点的动量代价产生？
12. 光型模式为何弱耗散、同速、成员替换而模式保持？
13. 介质如何改变光型模式的接力速度和到达时间？
14. 是否自然出现两个横向光学自由度？
15. 相变体的内部周期是否产生复相位？

## 十九、当前最精炼的理论表述


宇宙底层可能由一种高速运动、局部碰撞的深层基元构成。

均匀空间是这种基元的各向同性统计背景。

局部基元通过聚集、锁定和持续 in/out 交换形成有限相变体。

传播、运动、质量、惯性和力，不是预先赋予对象的属性，而可能分别对应：

- 传播：碰撞组织模式的空间接力；
- 运动：相变体与空间之间的定向 in/out 移动固定点；
- 质量：稳定相变体的静止能与改变运动固定点的动量代价；
- 惯性：重构整个 in/out 平衡所需的动量；
- 力：边界两侧动量通量统计不平衡；
- 场：底层碰撞分布的标量、矢量和张量统计矩；
- 量子概率：不可见深层状态经有限尺度观测通道后的统计投影；
- 希尔伯特空间：所有可能底层状态及长寿命慢模的状态函数空间；
- 递归：稳定相变体压缩为更高层有效对象；
- 对称性：稳定碰撞分布在状态变换下保持形式不变。

最小目标不是马上证明整个宇宙，而是先找到一个足够简单的底层更新规则，使以下结果能够无专用补丁地自然出现：

均匀背景
→ in/out 相变体
→ 移动固定点
→ 弱耗散传播模
→ 边界统计力
→ 慢模 Hilbert 结构
→ 分层递归。
